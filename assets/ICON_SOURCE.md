# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr), which provides ready-made logos for self-hosted applications.
No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/linkwarden.svg` | Default (light mode) |
| `icon-light.svg` | `svg/linkwarden-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/linkwarden-light.svg` | Light-colored logo for dark mode |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/linkwarden.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/linkwarden-light.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/linkwarden-dark.svg
